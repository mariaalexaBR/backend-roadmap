# Ejercicios

Código pequeño y enfocado, una carpeta por tema. Ejemplo:

```
ejercicios/
├── solid/srp/
├── patrones/strategy/
└── sql/indices/
```

Cada ejercicio lleva su `README.md` basado en [`plantillas/ejercicio.md`](../plantillas/ejercicio.md).
Primero lo resuelvo yo; después le pido a la IA que lo critique.
